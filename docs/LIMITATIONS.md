# Known limitations

- The evaluation uses 100 held-out contracts, and some clause types have only
  a few labelled examples, so per-clause scores are noisy.
- Some clause types remain weak, for example Volume Restriction and the
  Affiliate License types.
- Citation labels in the question-and-answer box point to section headings
  rather than the exact supporting sentence.
- On a free-tier host the live demo can take around 30 seconds to wake up.
- Output is decision support, not legal advice.
